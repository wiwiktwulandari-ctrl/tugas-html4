Apa Itu Web Development?

Web Development adalah proses membuat dan mengembangkan sebuah website. Website biasanya dibangun menggunakan HTML, CSS, dan JavaScript.

Tahapan Membuat Website

  1. Menentukan tujuan website
  2. Membuat struktur halaman
  3. Membuat desain
  4. Menulis kode
  5. Melakukan testing
  6. Melakukan deployment

  • JavaScript
  • PHP

  • Bootstrap

Istilah Web

Frontend
Bagian website yang berinteraksi langsung dengan pengguna.
Backend
Bagian website yang bekerja di sisi server.
Database
Tempat penyimpanan data aplikasi.
Framework
Kerangka kerja yang membantu developer membangun aplikasi.

Formatting Text

HTML digunakan untuk membuat struktur halaman. CSS digunakan untuk mengatur tampilan, sedangkan JavaScript digunakan untuk membuat halaman menjadi interaktif.
