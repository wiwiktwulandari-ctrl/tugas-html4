Apa Itu Algoritma?

Algoritma adalah langkah-langkah sistematis untuk menyelesaikan suatu masalah.

Sebelum membuat program, programmer sebaiknya memahami masalah dan solusi yang akan dibuat.

Langkah Membuat Algoritma

  1. Memahami masalah
  2. Menentukan input
  3. Menentukan proses
  4. Menentukan output
  5. Menulis langkah penyelesaian
  6. Menguji solusi

Struktur Dasar Algoritma

  • Sequence
  • Selection
  • Iteration

Contoh Struktur

  • Sequence
    • Input
    • Process
    • Output
  • Selection
    • IF
    • ELSE
    • SWITCH
  • Iteration
    • FOR
    • WHILE
    • DO WHILE

Istilah Algoritma

Input
Data yang dimasukkan ke dalam program.

Process
Tahapan pengolahan data.

Output
Hasil yang diberikan oleh program.

Flowchart
Diagram yang digunakan untuk menggambarkan atau menggambarkan alur algoritma.

Contoh Algoritma Sederhana

  1. Menyalakan alat pertama
  2. Memasukkan kopi ke dalam cangkir
  3. Menuangkan air panas ke dalam cangkir
  4. Mengaduk kopi
  5. Menambahkan gula

Algoritma yang baik harus jelas, logis, dan sistematis.

Berpikir sebelum coding! Jangan langsung menulis kode sebelum memahami masalah.
