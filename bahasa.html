Mengenal Bahasa Pemrograman

Bahasa pemrograman digunakan untuk memberikan instruksi kepada komputer. Setiap bahasa mempunyai karakteristik dan kegunaan yang berbeda.

Seorang programmer sebaiknya memahami konsep pemrograman, bukan hanya menghafal sintaks.

Contoh Bahasa Pemrograman

  1. Python
  2. Java
  3. JavaScript
  4. C++
  5. PHP
  6. Dart

Istilah Bahasa Pemrograman

Syntax
Aturan penulisan kode dalam sebuah bahasa pemrograman.

Variable
Tempat untuk menyimpan sebuah nilai atau data.

Function
Kumpulan instruksi yang dapat dipanggil untuk melakukan tugas tertentu.

Library
Kumpulan kode yang dapat digunakan kembali dalam sebuah program.

Tips Memilih Bahasa

Jika ingin membuat website, kamu dapat mempelajari HTML, CSS, dan JavaScript.

Jika tertarik dengan data, kamu dapat mulai belajar Python.

Jangan mencoba mempelajari semua bahasa sekaligus. Fokus pada satu bahasa terlebih dahulu.

Referensi

Kunjungi Python.org untuk mempelajari Python.
